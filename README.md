## 補足

- マラソンの2004年規程改定以前は、IAAFが「世界ベスト（world best）」として進化を管理していたが、コース計測・点呼・薬物検査等の要件が完全には統一されていなかったため公式批准はしていなかった。現在の規程下で遡及的に最初に批准されたのが Paul Tergat の 2:04:55（2003年9月）である。
- 100mは1977年1月1日以降、IAAFが世界記録に全自動電子計時（千分の1秒測定、百分の1秒で公認）を必須化。それ以前は手動計時の10分の1秒値が公認された。1968年Jim Hines の 9.95 は電子計時値で（手動計時値は 9.9）、後年の規程変更後も世界記録として継承された。
